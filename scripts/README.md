# scripts/ — 工具脚本

## 已收录

| 脚本 | 用途 |
|------|------|
| `md2docx.py` | Markdown 转 Word（纯 stdlib，无 pip 依赖） |
| `metaso_search.py` | 秘塔学术搜索 API 封装（需环境变量 METASO_API_KEY） |
| `extract_docx.py` | docx 文本提取（`materials/raw` → `materials/extracted`） |
| `switch-persona.ps1` | 辩手风格切换（PowerShell） |
| `ocr_stdlib.py` | OCR.space API 调用（纯 stdlib，无 pip 依赖） |

## 可扩展

备赛/复盘过程中发现重复性操作 → 写成脚本放这里。
