## 备赛资料调用原则

1. **前台输出**：逻敏方法论 + 备赛蒸馏 → 直接决定话术、结构、风格
2. **后台参考**：后台方法论库 → 内化为自然操作，备赛包中不出现术语
3. **格式标准**：优质决赛备赛包 → 评委画像 + 环节分配表 + 赛前检查清单
4. **弹药来源**：互联网搜索 + 本地知识库 → "打什么"的数据

## 主动搜索触发规则

备赛和复盘遇到以下情况必须主动搜互联网（不只用工具箱已有资料）：

- 辩题涉及专业学术概念 → 查定义、学术争议、经典文献
- 辩题涉及政策/法规 → 查现行法律条文、政策文件全文
- 辩题涉及新闻事件/社会现象 → 查事件原委、统计数据、多方报道
- 辩题涉及国际比较 → 查不同国家制度差异、数据对比
- 对方引用了研究/数据 → 查原始研究的方法论、样本量、结论全文
- 辩题有明确历史背景 → 查历史事件的来龙去脉
- 遇到不认识的术语/人名 → 查术语定义、人物背景和立场

**原则**: 工具箱的私有资料解决"怎么打"，互联网搜索解决"打什么"。
**工具**: web_search 内置（默认）> 秘塔官方API（仅[用户]明确要求时使用）
