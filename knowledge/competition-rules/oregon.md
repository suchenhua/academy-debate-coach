# 奥瑞冈赛制规则

## 概述

奥瑞冈（Oregon）辩论赛制源于美国大学辩论传统，以政策辩论（Policy Debate）为核心，强调证据质量、论证效率和政策损益比。台湾辩论圈是华语世界奥瑞冈辩论的主要推广者。

## 基本规则

- **赛制形式**：3v3（正方支持政策、反方反对政策）
- **发言顺序**：
  - 正方一辩申论 → 反方二辩质询正方一辩 → 反方一辩申论 → 正方三辩质询反方一辩
  - 正方二辩申论 → 反方三辩质询正方二辩 → 反方二辩申论 → 正方一辩质询反方二辩
  - 正方三辩申论 → 反方一辩质询正方三辩 → 反方三辩申论 → 正方二辩质询反方三辩
  - 结辩：反方先 → 正方后（或抽签决定）
- **发言时间**：申论5分钟 / 质询3分钟 / 结辩5分钟（具体时间因赛事而异）

## 核心原则

1. **论证负担**：正方承担"现状需要改变"和"改变带来净收益"的论证负担
2. **证据要求**：数据和事实是核心。无证据的断言视为未论证
3. **损益比**：核心判决标准是政策改变的"损益比"——收益是否大于成本
4. **需根解损**：需求性 / 根属性 / 解决力 / 损益比，四项缺一不可

## 评分维度及权重

| 维度 | 权重 | 评判要点 |
|------|------|----------|
| 论证完整性 | 30% | 需根解损四要素覆盖、逻辑链完整 |
| 证据质量 | 25% | 数据来源可靠、引证准确、证据与论点相关 |
| 交锋表现 | 25% | 质询有效性、回应质量、团队配合 |
| 损益比论证 | 20% | 利益与弊害的比较分析是否充分 |
