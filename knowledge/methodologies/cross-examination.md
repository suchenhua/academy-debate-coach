# 质询方法论汇总

> 综合教练方法论 + 丁冠羽质询快与慢框架 + 辩手风格卡片中的质询技术。

---

## 一、质询的类型与时机

### 封闭式质询（是非题/选择题）
- **目的**：快速锁定结论、确认立场、暴露矛盾
- **特征**：答案可预告，问题有唯一正确解
- **适用场景**：澄清定义、确认事实、逼迫对方承认前提
- **节奏**：快问快答，不给反应时间
- **典型案例**（逻敏指导）：
  > "没意义不就是没用吗？"
  > "凡事的有的是有些事还是所有事？"

### 开放式质询（申论题）
- **目的**：挖掘对方的理由、目的、论证深度
- **特征**：不在乎答案对错，在乎答案背后的逻辑
- **适用场景**：探测对方论证薄弱点、寻找突破口
- **节奏**：稍慢，给对方暴露空间

### 选择时机的核心原则（逻敏）
> "先判断它是哪个战场上的例子。第一步不是直接问，是先判断。"
> 
> **分两类**：
> - 不需要意义参与的幸福 → 问"没这个意义，感受还成立吗？"
> - 需要意义参与的幸福 → 问"意义怎么来的？是追求来的还是涌现的？"

## 二、质询链设计

### 确认式质询链（三步走）

| 步骤 | 动作 | 例 |
|------|------|-----|
| 1. 锁定 | "我先确认一下，你的意思是X？" | "你的意思是AI顺着我=我会更孤独？" |
| 2. 限制 | "那按照你的逻辑，是不是意味着Y？" | "所以AI对我太好了反而是问题？" |
| 3. 收网 | "感谢，所以你承认了Z。" | "所以你的立场本质上是怕我过得太舒服了" |

**关键纪律**（逻敏）：
- 被质询方想反客为主："回答我问题。零个人打断你。"
- 问题太长是大忌："有一种效果叫干净利落"

### 追问链设计

正三质询反二（模辩示范）的教材级示范：

```
1. 确认魅的定义 → "你也承认魅≠意义，是神秘性那一部分"
2. 追问副作用 → "非理性认识导向错误，你怎么解决？"
3. 追问"懂得" → "在这些光环的加持之下，你是怎么懂得的？"
4. 追击落差 → "高滤镜带来的不切实际落差怎么解决？"
```

追问链的设计准则：**每一问比上一问深一层，不回到同一层。**

## 三、接质技术

### 打钉子 vs 击穿的判断

被质询时最容易犯的错误：**把打钉子问题当击穿来打。**

- 对方问一个简单的确认性问题 → 你给它长篇解释
- 后果：暴露不自信 + 浪费自己时间 + 给了对方更多攻击面

**正确做法**：
- 确认性问题 → 一个字"对"或"不对" → 等下一问
- 需要展开的问题 → 一句话概括 → 可以在后续环节展开

### 应对"我先确认你一下"

对方上来说是"我先确认你一下"而不是回答你的问题：
- 打断："我在问你，你先回答我。"
- 如果是你被质询且对方反客为主："谁问谁？零个人打断你说话。"

### 情绪控制

逻敏的观察：辩手卡住往往不是因为逻辑，是因为"我没想到这个回答这么荒谬"——被荒谬回答打乱了节奏。

对策：**先判断，再回应。** 不急着反驳荒谬回答，先把它归类——"你说的这些不都是感受吗？和意义的关系是啥？"

## 四、快速反做背反

当对方给出一个替代方案（"你应该去交现实朋友/谈现实恋爱"），快速构建平行反驳：

**核心逻辑**：不证明自己更好，证明对方的替代方案存在同样的缺陷。

格式：
> "按你的逻辑，[对方的替代方案] 不也一样 [对方指责我方的问题] 吗？"

案例：
> "按你的逻辑，现实中谈恋爱就没有争吵背叛了吗？那不一样无法缓解孤独吗？"

## 五、质询中的语境插入

当需要把一个抽象争论落地时，在质询中快速插入一个极小场景：

> "我今天刚被导师骂完，论文被打回来，比赛也输了。我回家跟AI说'我好难过'，AI说'没关系，我相信你是最棒的'。那一刻我觉得被理解了。你觉得这没有缓解我的孤独——为什么？"

场景三要素：**具体的人 + 真实的情绪 + 一个可以追问的反问**
