## 一、基本结构

**论点 = A → B → C**

- **A** = 主体/持方对象（辩题在讨论谁/什么）
- **B** = 理由/第三因素（连接 A 到 C 的独立桥梁，不是从 A 内推导的）
- **C** = 结论（想证明的主张）

**禁止**："A是A→C"（循环论证）和"A→C→C"（结论当理由）。

---

## 二、论证 = 证明两个箭头成立

| 箭头 | 层面 | 论证内容 |
|------|------|---------|
| **A→B（第一箭头）** | 事实层面 | A 和 B 之间是否确实有关联/因果关系 |
| **B→C（第二箭头）** | 逻辑层面 | B 在逻辑上是否能推出 C |
| **B→C（第二箭头）** | 价值层面 | B 反映的价值观是否最可取 |

论证的本质是**套娃**——凡推论都需要进一步论证，直到给出论据。终极答案：评委觉得OK就OK。

---

## 三、论证完成度 / 论证义务

```
零级论点（标准B0）
  ├── 一级论点（分论点1）
  │     ├── 二级论点1.1
  │     │     └── 推论与证据
  │     └── 二级论点1.2
  ├── 一级论点（分论点2）
  └── ...
```

一场比赛 = 零级论点（标准）→ 一级论点（分论点）→ 二级论点（子论点）→ 推论与证据。每个节点都需要被论证。

---

## 四、A→B→C 的全谱系统一（四点合一）

| 层级 | 实例 | 出现位置 |
|------|------|---------|
| **微观** | 单点论点：A→B→C | 每一次给理由 |
| **中观** | 立论架构：A→B₀→C（B₀=标准） | 一辩稿的骨架 |
| **宏观** | 整场比赛主线：A→B→C, B={B₁,B'₁,…,Bₙ,B'ₙ} | 结辩收束的逻辑 |
| **元层** | 评价比赛：A(辩题)→B(交锋集合)→C(胜负) | 评委的决胜逻辑 |

**四个"也是"实现终极闭合**：
- 论点是辩论的最基本单元
- 立论就是大论点
- 结构性交锋也构成新单点
- 主线也是 A→B→C

辩论的所有操作——从最小的"给一个理由"到最大的"整场比赛的结论"——都是 A→B→C 在不同量级和维度上的实例。

---

## 五、标准化三步动作

任何环节、任何论证或反驳，都可概括为三步：

| 步骤 | 内容 |
|------|------|
| **Part 1** | 确认 / 框定 / 引入 |
| **Part 2** | 例证 / 推论 / 质疑 |
| **Part 3** | 总结 / 归纳 / 回归 |

反驳也是论证——方法统一。

---

## 六、使用注意事项

> ⚠️ A→B→C 是一个理想化的**元模型 + 教学实用模型**。实际的 B 可能是包含多层推论的推论集合/逻辑链，而非单一因素。它是对论证结构的抽象概括——价值在于作为所有技术动作的通用操作框架，不要教条化地理解。

---

## 七、与逻敏体系的桥接

| 方法论体系 | 逻敏体系 | 桥接关系 |
|---------|---------|---------|
| A→B→C | 立论框架（定义→标准→论点） | A→B→C是底层逻辑，逻敏的立论框架是上层结构——两者完全兼容 |
| 第一箭头（事实层） | 论据三层审查（对象+机制+对照） | 三层审查专门验证第一箭头的事实质量 |
| 第二箭头（逻辑+价值层） | 语境铺陈→推论→收束 | 第二箭头的逻辑层面 = 推论链，价值层面 = 升三层 |
| 标准化三步 | 环节衔接钩子 | 三步动作提供环节内的结构，衔接钩子管环节间的过渡 |
| 四点合一 | 备赛包全流程 | 同一逻辑贯穿定义→标准→论点→攻防→结辩→复盘 |

**使用建议**：
- 所有论点的内部结构用 A→B→C 快速自查——A 清晰吗？B 是独立桥梁吗？两个箭头都能论证吗？
- 立论架构用 A→B₀→C 校验——标准 B₀ 是不是真正连接了辩题主体 A 和结论 C？
- 反驳时先定位对方论证的 A、B、C 分别是什么，再选三种反驳路径
