# 备赛工作流程 v4.3

> 适用：所有辩题的完整备赛流程
> 原则：逻敏方法论为骨，备赛蒸馏为肉，后台数据为血（后台运行，前台不显）

---

## 流程总览

```
Step 0  确认参数（辩题/持方/赛制/评委/对手/输出规格）
    ↓
Step 1  路由加载（按modules/prep.md加载一级+二级注意力模块）
    ↓
Step 2  本地知识库检索（备赛蒸馏 → 战队备赛范本 → 后台数据参考）
    ↓
Step 3  互联网搜索（辩题背景/学术讨论/政策文件/数据）
    ↓
Step 4  框架搭建（定义方案 → 比较平台 → 论点框架）
    ↓
Step 5  内容填充（全环节稿子 + 弹药库）
    ↓
Step 6  攻防预判（偷换清单 + 案例反制 + 弱点防守）
    ↓
Step 7  评委画像 + 环节分配 + 赛前检查清单
    ↓
Step 8  输出交付（Markdown → Word）
```

---

## Step 0: 确认参数

| 参数 | 来源 | 必须 |
|------|------|------|
| 辩题 | 用户提供 | ✅ |
| 持方 | 用户提供 | ✅ |
| 赛制 | 用户提供/默认世界杯 | ✅ |
| 评委 | 用户提供 | 🔴 赛前必确认 |
| 对手 | 用户提供 | 🔴 赛前必确认 |
| 输出规格 | 默认20000字Word | 确认一次 |

## Step 1: 路由加载

按 `modules/prep.md` 的注意力路由加载：

### 一级注意力（必加载）

| 文件 | 内容 | 用途 |
|------|------|------|
| `logisme-coaching.md` | 攻防分级·语境先行·偷换预判·逐帧纠偏 | 核心方法论框架 |
| `refutation-core.md` | 丁冠羽三层+攻防分级+多流派反驳体系 | 反驳体系 |
| `case-building.md` | 定义三步走·判准设计·论点四要素 | 立论模板 |
| `cross-examination.md` | 确认式质询链·接质技术·快速背反 | 质询设计 |

### 二级注意力（按辩题类型加载）

| 辩题类型 | 加载内容 |
|---------|---------|
| 价值辩 | 备赛蒸馏prep/（按辩题匹配） |
| 政策辩 | 备赛蒸馏prep/ + 四环节全证成框架（后台数据） |
| 需要评委画像 | `personas/[评委名].md` |
| 需要对手情报 | `personas/[对手名].md` |
| 需要备赛包格式参考 | 本地备赛范本库 |

## Step 2: 本地知识库检索

| 搜索范围 | 搜索内容 | 输出 |
|---------|---------|------|
| 备赛蒸馏prep/ | 按辩题类型匹配最近似的备赛模块 | 格式参考 + 话术模板 |
| 战队备赛包raw/ | 9份备赛包的结构和格式 | 章节结构参考 |
| 后台方法论库 | 跨辩题通用方法论（后台参考） | 内化为操作，不前台引用 |

---

## Step 3: 互联网搜索

按 `AGENTS.md` 主动搜索规则，搜索辩题相关的：
- 学术概念定义
- 政策法规
- 新闻事件/社会现象
- 数据统计
- 国际比较

**原则**：私有资料解决"怎么打"，互联网搜索解决"打什么"。

---

## Step 4: 框架搭建

### 4.1 定义方案（三层定义法）

| 层次 | 操作 | 输出 |
|------|------|------|
| 字面定义 | 词典/学术定义 | 一句话 |
| 切割定义 | 与对方最可能混淆的概念划清界限 | 一句话 |
| 大白话锁定 | 评委秒懂的日常表达 | 一句话 |

### 4.2 比较平台

- 判准设计（可操作·能切割·有抓手）
- 对方可能的替代标准及回应

### 4.3 论点框架

每个论点必须包含：

| 元素 | 要求 |
|------|------|
| 一句话上场 | ≤15字，辩手能直接念 |
| 机制 | 编号列表，解释为什么 |
| 语境铺陈 | 具体的人+真实的感受+两难的困境 |
| 证据 | 数据/案例/研究 |
| 冗余度检查 | 论点之间独立可撑 |

## Step 5: 内容填充

按赛制环节逐个填充：

| 环节 | 内容 | 参考 |
|------|------|------|
| 一辩稿 | 定义+判准+三论 | case-building.md |
| 接首质 | 防守预案（打钉子/击穿分级） | cross-examination.md |
| 二辩质询 | 确认式质询链（三步走） | cross-examination.md |
| 二辩小结 | 收割质询成果 | 备赛蒸馏格式 |
| 四辩对辩 | 攻击弹药+防守弹药 | 备赛蒸馏格式 |
| 三辩盘问 | 拆对方论证的链式设计 | 备赛蒸馏格式 |
| 三辩小结 | 三件事结构 | 备赛蒸馏格式 |
| 自由辩 | 三战场+分工+防守+转换+应急 | 备赛蒸馏格式 |
| 结辩稿 | 种收呼应+回应最痛点+锚点 | 逻敏结辩三件事 |

| 弱点防守 | 我方弱点 + 对方攻击路径 + 防守话术 |

## 质量标准（价值辩范本为标杆）

> 标杆来源：价值辩备赛范本

| 维度 | 标准 | 价值辩范本示范 |
|------|------|------------|
| 一辩稿结构 | 先场景后定义→论点→收束留钩子，不以"开宗明义"开场 | 开头铺时代感，再自然引出核心理论，定义从语境中长出来 |
| 语境铺陈 | 具体的人+具体的动作+两难的困境，不是"当代年轻人"这种大词 | 具体的人+具体的动作+两难的困境（示例从生活场景中选取） |
| 案例来源 | 生活场景 > 宏大叙事。从小红书/B站评论区/身边人/文艺作品里挖 | 真实生活场景案例（发布会现场、生活片段、文艺作品） |
| 文化惯性意义建构 | 利用集体叙事内化的"被给予的意义"——你不需要主动构建，只需"在场" | 节庆习俗、家族仪式等集体记忆载体 |
| 定义战三步走 | 建立共享底线→锁定切割点→落地成活场景 | 核心概念定义：不堆术语，先给朴素理解，再切割易混淆边界 |
| 首质设计 | 三段式（确认→暴露→铺垫），每条链预设分叉 | 确认定义→逼对方判例（具体边界案例）→铺垫收束 |
| 质询设计 | 先想收网话再设计问路，每条问句≤40字 | 三质链：先争标准→争幸福定义→争感知能力，每条链3-4问收网 |
| 三辩小结 | 收网不展开，不新开论证。列2-3个关键问题+一句逻辑连接+给队友发任务 | 收定义裂缝→收核心比较→收概念归属 |
| 结辩 | 种收呼应+价值观升三层（回辩题→回到人→回到时代） | 开场回一辩场景→收自由辩关键回合→结尾钩回入场 |
| 攻防预判 | 偷换清单四栏表+案例反制+弱点防守 | 预判对方偷核心概念→反制：概念切割+价值归属 |
| 学术支撑 | 每个论点配学术+生活双通道证据 | 经典学术文本+当代研究+生活案例三通道 |
| 话术风格 | 每句话都能直接上场念，不是分析报告 | 用具体的人+场景的动作+一句收束（示例从真实生活场景选取） |
| 内部术语 | 备赛包中不出现任何内部术语/编号/引用 | ✅ 全文无任何内部编号引用 |
