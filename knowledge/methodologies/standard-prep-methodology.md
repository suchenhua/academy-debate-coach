## 一、设计哲学

**备赛不是线性写作——是两轮循环。**

第一轮：搜集→汇编→穷举→架构（广撒网，不评判）
第二轮：防守→攻击→套题→再汇编→导出（精选，结构化）

很多备赛的失败不是因为"想得不够深"，而是因为"跳过了穷举直接选"——写了三个论点就觉得够了，其实最好的那个根本没被列出来。

---

## 二、九步流程

```
E1 资料搜集 ──→ E2 资料汇编1.0 ──→ E3 论点穷举 ──→ E4 论证架构
                                                          │
E9 导出备赛包 ←── E8 资料汇编2.0 ←── E7 自由辩套题 ←── E5 防守体系
                                                          │
                                                    E6 攻击体系
```

## 三、逐步详解

### E1：资料搜集（四维）

| 维度 | 内容 | 最低要求 |
|------|------|---------|
| **关键词解释** | 辩题每个关键词至少3条不同来源的解释 | 每个词3条 |
| **类似案例/调查** | 公共事件、学术调查、历史案例 | 至少2条 |
| **热点事件** | 近期相关新闻/社交媒体讨论 | 至少2条 |
| **专业理论** | 学术理论框架、经典文献观点 | 至少2条 |

### E2：资料汇编1.0（去重→合并→归类）

第一轮汇编。把E1搜集的资料按论证方向归类——每条资料标注："支持分论点1 / 范围支撑 / 反驳对方 / 背景铺垫"。

**关键操作**：去重（同质资料合并）+ 归类（每个资料找到它在论证树上的位置）。

### E3：论点穷举清单

**不筛选、不评判。** 把能想到的所有论证方向全列出来——"因为…所以…"格式。默认建议20条起。

**为什么先穷举再选**：人脑有确认偏误——第一个想到的论点会被高估。穷举强迫你列出第5个、第10个、第15个——往往第8个是最好的。

**操作纪律**：在这个阶段不评价任何论点。"这个太弱了吧"——也写上去，后面自然会淘汰。

### E4：论证架构 + 环节任务分配

从E3的穷举清单中筛选，搭建：定义 → 标准B0 → 分论点(N个) → 环节任务分配。

**环节任务分配**：不是只列论点——每个环节（立论/质询/小结/自由辩/结辩）各承担什么论证任务，提前分配好。

### E5：我方防守体系（四列表）

每个防守点四列：

| 对方可能攻击 | 对方可能论据 | 我方回应 | 我方论据 |
|------------|------------|---------|---------|

**防守覆盖清单**：
- 定义层：定义过宽/过窄、定义回避核心争议
- 讨论范围：范围切入的合法性攻击
- 标准B0：B→C推不通 / B不重要（有更重要的判准）
- 每个分论点：按三种反驳路径（A→B / B→C / B不重要），每种路径内部行数自定

### E6：我方攻击体系（G系列编号）

按对方可能论点穷举攻击路径。每个对方论点配：
1. **完整A→B→C链条**（对方的论证逻辑）
2. **对方最可能引用的证据**
3. **三种反驳类型**（A→B事实 / B→C逻辑 / B不重要价值）
4. **G系列编号**——给每条攻击分配唯一编号（G1/G2/G3…），方便后续引用

### E7：自由辩套题（问→追→归→转）

每个战场一条完整链：

| 步骤 | 动作 | 说明 |
|------|------|------|
| **问** | 锁定立场 | 一个问题把对方框在某个立场上 |
| **追×2** | 预判回应追问 | 对方答A→跟进B；答C→跟进D。每条链至少2层追问 |
| **归** | 收束到我方 | 把追问引出的矛盾收束到我方框架 |
| **转** | 切下一战场 | 过渡句，自然衔接下一个战场 |

每条链末尾有过渡句，切入下一战场。

### E8：资料汇编2.0（第二轮精编）

架构定型后，第二轮汇编——把E2的原始资料按F/G编号重新归类，删除未使用的、补充新发现的缺口。

**分类维度**：定义/讨论范围、标准B0、分论点1/2/3…

每类标注F/G编号，对应攻击/防守体系中的引用。

### E9：导出备赛包（六项自检）

| # | 检查项 | 内容 |
|---|--------|------|
| 1 | 信息一致性 | 各表B0/分论点措辞统一 |
| 2 | 论证连贯性 | 论证顺序与E4最佳序一致 |
| 3 | 攻防一致性 | 成文稿对齐E6攻击路径 |
| 4 | 时间匹配 | 各环节时长与稿件字数匹配 |
| 5 | 自由辩闭环 | 每个战场有问-追-归完整链 |
| 6 | 物资准备 | 资料稿件打印、服装准备就绪 |

## 四、与逻敏体系的融合

### 对现有prep-coach的增强

| 标准备赛九步法 | 逻敏prep-coach | 增强点 |
|-----------|---------------|--------|
| E3 论点穷举（20条起） | Phase 3 论点架构（2-3个） | **前置穷举阶段**——先在E3列20条再选，避免遗漏最佳论点 |
| E2+E8 两轮资料汇编 | Phase 2 资料搜集（一轮） | **增加第二轮精编**——架构定型后重新归类资料 |
| E5 防守四列表 | 攻防预判（偷换清单） | **结构化防守表**——每个防守点配四列（对方攻击/论据/我方回应/论据） |
| E6 G系列编号 | 无 | **攻击路径编号体系**——每条攻击唯一编号，全文贯通引用 |
| E7 问追归转 | Phase 4 自由辩弹药库 | **自由辩结构化**——每个战场配完整链而非孤立弹药条 |
| E9 六项自检 | Phase 5 输出 | **交付前自检清单**——尤其"攻防一致性"和"时间匹配"是关键 |

### 操作建议

**推荐的融合方式**——prep-coach Phase 3（框架搭建）前插入"论点穷举"环节：

```
Phase 1 情报分析
Phase 2 资料搜集（第一轮）
  └── 🆕 资料汇编1.0（去重归类）
Phase 3 🆕 论点穷举清单（20条起，不评判）
Phase 4 框架搭建（从穷举清单中筛选）
  ├── 定义 → 标准B0 → 分论点
  └── 环节任务分配
Phase 5 攻防体系
  ├── 🆕 防守四列表（对方攻击/论据/我方回应/论据）
  └── 🆕 攻击G系列（每种反驳路径编号）
Phase 6 🆕 自由辩套题（问追归转 × N个战场）
Phase 7 内容填充（按赛制适配）
  └── 🆕 资料汇编2.0（第二轮精编）
Phase 8 输出交付
  └── 🆕 六项自检
```
