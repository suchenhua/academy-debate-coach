# 华语辩论黑话 & 术语表

> 从比赛逐字稿、评委点评中持续积累。用于理解辩坛语境和提升基础认知。
> 初次建档: 2026-06-24 · 来源: 方法论体系 + 2026新国辩

---

## 一、赛事术语

| 术语 | 含义 |
|------|------|
| **印象票** | 评委第一票，基于整体观感和立论质量 |
| **环节票** | 评委第二票，基于各环节（质询/对辩/自由辩）表现 |
| **决选票** | 评委第三票，综合决定胜负 |
| **分票** | 评委将三票投给不同持方 |
| **述票** | 评委公布投票理由和评价 |
| **心证** | 评委个人主观判断和偏好 |
| **地板论** | 最低限度的论证要求——只要逻辑自洽、不严重荒谬即成立 |
| **定义战** | 双方对核心概念的定义争夺 |
| **战场** | 攻防聚焦的具体议题/争论点 |
| **收割** | 在自由辩后将前面的优势汇总收束 |
| **收束** | 结辩时对全场攻防的总结和升华 |
| **推战场** | 主动推进争议点到下一个环节 |

## 二、攻防术语

| 术语 | 含义 | 出处 |
|------|------|------|
| **打钉子** | 一句话确认→打完就截，不展开 | 逻敏 |
| **击穿** | 语境→例子→推论→收束，四步完全翻转对方论点 | 逻敏 |
| **偷换** | 对方对概念/比较标准/因果路径的不正当替换 | 逻敏 |
| **反弹** | 用对方的逻辑推回对方的其他论点 | 通用 |
| **归谬** | 将对方论点推至荒谬结论 | 通用 |
| **切割** | 将对方证据/案例与论点之间的关联切断 | 通用 |
| **受身** | 承认对方部分论点但论证其不影响核心比较 | 通用 |
| **相抗** | 指出对方两个论点内在矛盾 | 通用 |
| **推极端** | 将对方逻辑推到极限情况检验合理性 | 通用 |

## 三、立论术语

| 术语 | 含义 |
|------|------|
| **判准** | 判断该辩题的标准/尺度，立论的核心基线 |
| **比较标准** | 双方都接受或一方提出的衡量优劣的标尺 |
| **框架** | 整体论证结构的顶层设计 |
| **推论** | 纯逻辑推理（区别于数据/案例），说服力最强 |
| **论域** | 论证覆盖的范围/边界 |
| **操作定义** | 为比赛目的重新界定概念含义 |
| **劣势持方** | 公认更难打的持方位置 |

## 四、评委评语常用词

| 用语 | 含义 |
|------|------|
| **论证门槛** | 论点成立需要的最低论证程度 |
| **交锋** | 双方在同一议题上的直接对抗 |
| **后场新点** | 结辩/自由辩后期才出现的新论点 |
| **推翻共识** | 后续否认之前质询中达成的共识 |
| **场上存在感** | 论点在比赛进程中被讨论和交锋的程度 |
| **溢出的论证** | 超出立论框架的延伸论证 |

## 五、辩坛黑话

| 黑话 | 含义 |
|------|------|
| **地板** | 最低标准（来自"地板论"） |
| **吃地板** | 接受了对方的最低标准论证 |
| **撞车** | 双方论点重合/不冲突 |
| **爆点** | 出乎意料的有效攻击 |
| **起效果** | 论点/反驳实际影响了评委判断 |
| **堆东西** | 只堆砌论据不做推论 |
| **念稿** | 照读一辩稿，缺乏临场应变 |
| **做比较** | 不只在己方立场论证，还要说明为什么比对方好——新国辩评判核心 |

## 六、2026新国辩实战术语（从比赛中提取）

### 方法论术语

| 术语 | 含义 | 出处 |
|------|------|------|
| **奥卡姆剃刀** | 如无必要勿增实体——辩论中用于划定举证责任：谁主张改变现状谁举证 | 半决赛2·洪敦敏 |
| **上行反事实思维** | 心理学概念：遗憾驱使人们想象更好的结果，在后续任务中表现更深思熟虑+更高执行力 | 决赛·正方一辩柴子凡 |
| **默会知识** | 不可言传只可意会的实践知识——库里投篮的手感、木工手艺 | 半决赛1·反方 |
| **语义知识 vs 默会知识** | 前者可被语言编码传承，后者只能靠身体实践 | 半决赛1·张哲耀述票 |
| **罗格斯中心主义** | 西方哲学传统：认为语言=理性=真理，唯有能被清晰言说的才具备进入真实世界的资格 | 半决赛1·反方立论 |
| **绩效社会** | 韩炳哲概念：现代资本主义将一切行为量化、效率化、可计算化 | 半决赛2·正方立论 |
| **同质化地狱** | 韩炳哲概念：绩效社会消灭他者性和风险后形成的精神荒漠 | 半决赛2·正方立论 |
| **防卫性独身** | 因害怕受伤而主动选择不进入亲密关系 | 半决赛2·正方立论 |

### 判准术语

| 术语 | 含义 | 出处 |
|------|------|------|
| **白纸裁 vs 非白纸裁** | 评委是否只裁场上呈现（白纸）还是可以带入个人解读（非白纸） | 张哲耀/胡渐彪述票分歧 |
| **涟漪论** | 张哲耀的判准：辩手表达是石子，激发的思考是涟漪——涟漪也是评判边界 | 半决赛1·张哲耀述票 |
| **动机解读** | 胡渐彪的判准：不仅看说的文字，还要结合辩手的时间点和表达动机来判断是否"正面回应" | 半决赛1·胡渐彪述票 |
| **平票** | 评委投出平票——新国辩三轮票制中环节票可以平 | 半决赛1·万华明 |

### 战术术语

| 术语 | 含义 | 出处 |
|------|------|------|
| **首质** | 第一轮质询（反方四辩质正方一辩/正方四辩质反方一辩） | 通用 |
| **切人群** | 将某类人排除出辩题讨论范围以简化论证 | 半决赛2·正方（被评委批评） |
| **全称论证困境** | 当对手用单个反例反驳你的普遍主张时，你的论证面临的压力 | 半决赛2·王鑫述票 |
| **跳着打** | 不停切换攻击线路，缺乏连贯性。多被评委批评 | 半决赛2·王彤述票 |
| **追/被追** | 语言追不上人类认知——类似于"语言的边界总是在追赶人类的边界"的比喻 | 半决赛1·反方四辩张泽平 |
