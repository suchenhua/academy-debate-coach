# 结构化表达：让评委听得懂

> 来源：橘桔如律令《有理说得清：新手辩论实用指南》，微信公众号"辩论"（华语辩论网）
> 收录日期：2026-06-23

---

## 核心观点

好的表达，不是你说得爽，是让对方听得懂。辩论其实是打给评委听的。

表达和倾听是辩论的两只手：一只手把炮弹打出去，另一只手接住对方的炮弹。

---

## 三个结构化表达原则

### 1. 结论先行

**先说结论，再说理由。**

人的注意力有限。先说一堆理由 → 听众边听边猜"他想说什么" → 跟丢。先说结论 → 听众知道"他要讲这个" → 跟着理由走。

**错误**："对方同学提到了很多数据，但这些数据来源不明，而且样本量太小，另外他们的推论也存在问题……"

**正确**："对方的数据不可靠。第一，来源不明；第二，样本太小；第三，推论有问题。"

### 2. 要点分类

**用"第一、第二、第三"分开每个点。**

数字是最好的路标。告诉听众：这里换话题了。

**错误**："这个政策会增加企业成本，而且员工也不一定乐意，另外执行起来也有难度……"

**正确**："这个政策有三个问题。第一，增加企业成本；第二，员工不一定乐意；第三，执行有难度。"

评委记笔记时最省心：记下"1.增加成本 2.员工不乐意 3.执行难度" → 你的点刻在脑子里。

### 3. 金字塔结构

```
核心观点
    / \
论点1  论点2
  / \   / \
论据 论据 论据 论据
```

- **最顶上**：你的核心主张
- **第二层**：分论点
- **第三层**：每个分论点下的数据和案例

**一场立论稿就是金字塔**：立场(顶) → 两个分论点(中) → 数据案例(底)

**一次两分钟陈词也是金字塔**：我要反驳什么(顶) → 从两个角度(中) → 各用一句话(底)

好处：评委可从任何层次进入，不影响整体理解。

---

## 场上应用

- **接质时**：先给结论（"我方认为不是"），再给理由（"因为……"）。不要倒过来
- **小结时**：第一第二第三分开，评委好记
- **立论时**：整个一辩稿就是一座金字塔
