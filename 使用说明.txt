========================================
  逻敏 · Academy 辩论教练
  给第一次用的人看的说明
  ⚡ 本地运行 · 数据不出本机
========================================

【这个软件是干什么的】
它是一个装在你自己电脑里的辩论 AI 教练。
可以帮你：备赛（立论/质询/攻防）、复盘比赛文字稿、当评委打分述票。
内置逻敏方法论体系（已脱敏蒸馏，不含任何原始资料和个人隐私）。

【怎么打开】
最简单：双击「Academy辩论教练-安装版.exe」，等它装完，会自动打开一个桌面窗口。
以后双击桌面上的「Academy辩论教练」图标即可，不需要黑色窗口。

如果没有安装版 exe（拿到的是压缩包）：
1. 把这个压缩包解压到一个文件夹（右键 → 全部解压缩）。
2. 打开文件夹，双击「一键安装.bat」，装完会自动打开桌面窗口。
3. 不想安装也可以直接用：
   - 双击「启动辩论助手(Electron桌面版).vbs」或 start.bat —— 自带 Chromium 的独立桌面窗口，
     没有黑窗口、没有浏览器标签栏/地址栏，关掉窗口 = 退出程序。
   （旧版浏览器模式已移除；若确实想在浏览器里看，程序运行期间访问 http://127.0.0.1:8787 即可）
详见「安装说明.txt」。

【第一次使用：填 API】
1. 页面右上角点「设置」。
2. 选 API 服务商：
   - DeepSeek 官方：去 https://platform.deepseek.com 注册充值，创建 Key
   - 也可以用硅基流动 / Moonshot / 智谱 / 任意 OpenAI 兼容接口
3. 把 API 地址、Key、模型名填进去，点「保存」（可先点「测试连接」）。
   联网搜索默认免费（端侧搜索，不扣任何 API 余额）；不要填 DeepSeek 搜索 Key。
4. 以后打开就不用再填了。

【怎么用】
- 左侧选模式：自由问答 / 备赛 / 复盘 / 评判
- 下面输入框打字，按 Ctrl+Enter 发送（或点发送按钮）
- 复盘时：把比赛文字稿整段粘贴进去，或点 📎 上传 txt/md/srt 文件；**PDF 资料也能传**（自动提取文字）
- **双击 .md / .txt / .srt 用「轻量阅读窗」打开**：只弹一个小窗（秒开、不用启动整套 App），可置顶 /
  调字号 / 深色 / 复制全文 / 导出 Word，也能一次开多个并排、和主窗口同时用；想深加工就点
  「🎓 在 Academy 接着做」跳回完整版
  - **能直接编辑**：点「✏️ 编辑」（或双击正文 / Ctrl+E）切换到编辑，Ctrl+S 保存回原文件，
    未保存关闭会提醒；若文件在你编辑期间被别的程序改过，会先问你要不要覆盖，不会悄悄覆盖
  - 主 App 里的「📖 MD 阅读器」（工具箱）同样能编辑，用法一致
- 想查资料：点右上角「🧰 工具箱」→「🔍 搜资料」→ 输入关键词 → 结果带来源分类（学术/政策/新闻/百科），可「＋ 插入输入框」；
  搜索时可切换通道：🆓 端侧（免费 Bing/DuckDuckGo）或 🛰 服务侧（走当前模型商的原生搜索，结果更准、扣模型余额）
- 等待几秒，回答会像打字一样逐字显示（流式输出），随时可点「停止」
- 完成任务后仍可点开「💭 思考过程」和查看工具调用记录；每条回复下方显示 token 用量（输入/缓存/命中率/输出/上下文占比），
  输入框下方常驻「本对话 Token」统计，含「上下文已使用占比」
- 顶部「🧹 压缩上下文」可把当前长对话压缩成摘要，释放上下文空间
- 每条回复下面有「复制」「Word」「PDF」「导出」按钮；右上角点「⬇ 导出当前会话」→ 下拉菜单选 Word / Markdown / PDF，把整场对话导出成文档
- 顶部「🧰 工具箱」里有搜资料、辩案工作台、流水单等工具

【📦 产物空间：教练的交付文件】
- 让教练写「备赛包 / 复盘报告 / 述票词 / 数据清单」等长篇时，它会存成文件到产物空间
- 顶部「📦 产物」可以：预览 / 转 Word（md）/ 转 Excel（csv）/ 存 PDF / 导出到任意文件夹 / 打开所在文件夹 / 删除
- 产物保存在本机 data\deliverables\，不上传；想带走就点「导出到文件夹」选个位置
【🧩 技能 / 插件：给教练加新本领】
- 打开 ⚙️ 设置 → 「🧩 技能 / 插件」→ 点「导入技能文件」选一个 .md，或点「＋ 新建（粘贴）」直接写
- 技能文件格式：开头用 --- 包一段说明，至少含 name（英文名）与 description（什么时候用、做什么）
- 装上后，下次任务会提示教练按需加载；面板里可随时「停用 / 编辑 / 删除」
- 技能存放在本机 data\.dsh\skills\，不随软件更新覆盖，重装不丢
【📚 个人资料库：让你自己的资料参与备赛】
- 点顶部「📚 资料库」→ 把文件拖进去，或「选择文件」/「粘贴文本」
  （支持 txt / md / srt / pdf / docx，单份 ≤ 16MB，可多选）
- 适合放：自己的备赛包、模辩文字稿、期刊摘录、教练笔记、常用数据与口径
- 之后每次备赛 / 复盘，Agent 会**自动检索**你的资料并优先引用其中的数据、口径和话术；
  回复上方会显示「📚 本次召回你的资料：《xxx》」；需要全文时 Agent 会自己去读
- 弹窗里可「预览 / 暂停召回 / 删除」；不想让它检索时，关掉「自动检索资料库」开关
- 弹窗里的「试检索」可以先看一眼：这个词会召回哪些资料
- **图片（截图）也能传**：png / jpg / bmp 会自动用 Windows 自带 OCR 识别成文字入库，全程在本机完成、不上传
- 扫描件 PDF 没有文字层：用 WPS / Word 打开另存为 docx 再传，或截图成图片传（自动 OCR）
- 弹窗里「🔁 同义词」可自己加组（一行一组，如「人工智能,AI,AIGC,大模型」），
  让「AI」也能召回写着「人工智能」的资料
- 资料只存在本机 data\library\，不上传任何服务器
- 「设置 → 数据备份 → 一键导出」现在会带上资料库的正文（不含原件），换电脑导入即可恢复

【常见问题】
Q：提示"还没配置 API Key"？
A：点右上角设置，填 Key 保存。

Q：提示"Agent 内核缺失"？
A：解压不完整，重新解压整个压缩包，不要只拷贝其中几个文件。

Q：点了发送很久没反应？
A：正常，复杂任务要几分钟。可以点「停止」再试。

Q：换电脑能用吗？
A：能。把整个文件夹拷过去（或重新解压压缩包），双击 start.bat 即可。
   如果文件夹已经用过，移动前先删掉里面的 data 文件夹，到新位置再启动（配置会重新生成，Key 需要重填一次）。

Q：资料会泄露吗？
A：所有资料都在你自己电脑里；API Key 只发往你在设置里填写的那个 API 地址。
