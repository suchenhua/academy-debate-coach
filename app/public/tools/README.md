# tools/ — 辩论工具集

> 来源：精靈Moon《辩论筑基》（GitHub: MoonTzai/debate-coach，CC BY-NC-SA 4.0）
> 均为自包含HTML文件，浏览器直接打开即可使用。

| 工具 | 文件 | 用途 |
|------|------|------|
| 🏗️ **辩案工作台** | `辩案工作台-Case-Workbench.html` | 标准化备赛九步法——资料搜集→汇编→论点穷举→架构→防守→攻击→自由辩套题→再汇编→导出 |
| 📝 **简易流水单** | `简易流水单-Flowing-Tool.html` | 比赛现场记录双方攻防，结构化流水 |
| 🎙️ **语音与口条练习** | `语音与口条练习-Voice-Practice.html` | 语音语调/口条流畅度训练工具 |

## 使用方法

1. 浏览器打开对应 HTML 文件
2. 数据仅保存在浏览器本地（localStorage），不会上传
3. 辩案工作台支持导出完整辩案文档
