📁 数据位置

所有个人数据都保存在程序目录的 data 文件夹里（data/chats 对话、data/memory.md 记忆、data/config.json 配置）。 整个文件夹复制走就等于完整备份；也可以用上面的按钮生成单文件备份。

⚠️ 备份文件包含你的 API Key，请只保存在自己的设备或网盘，不要发给别人。

👋 欢迎使用逻敏 · 辩论教练

这是一个本地运行的 AI 辩论教练。

  • ✅ 对话、资料、记忆都只存在你自己的电脑上，不上传任何服务器
  • ✅ 覆盖备赛 / 复盘 / 评判 / 自由问答四种模式，各自独立
  • ⚙️ 只需配置一次：填一个 AI 服务的密钥（API Key）

下面三步，大约 3 分钟就能搞定。

第 1 步：申请一个 API Key

  1. 点下面的按钮打开 DeepSeek 开放平台（国内可直连，价格便宜）
  2. 用手机号注册并登录
  3. 左侧菜单找到 「API Keys」 → 点 「创建 API Key」
  4. 复制那串 sk- 开头的密钥（只显示一次，先粘到记事本）
  5. 在平台里充值几块钱（按用量扣费，很便宜）

💡 不会操作？找队里用过 AI 的队友帮忙，5 分钟就能弄好。

第 2 步：把 Key 粘贴进来

Key 只保存在本机 data/profiles.json，不会上传到任何第三方服务器。

⚙️ 高级选项（使用其他模型服务商）
填好后点下面的「测试并保存」，会用这里的地址和模型去验证。

✅ 配置完成，可以开始用了！

  • 顶部选模式：备赛 / 复盘 / 评判 / 自由问答（各模式对话互相独立）
  • 输入内容后按 Ctrl+Enter 发送
  • 📎 可上传 Word / PDF / txt 资料，🔍 可联网搜资料
  • 🧰 工具箱里有辩案工作台、流水单、语音练习等，🧠 会记住你的偏好

随时可在 ⚙️ 设置里更换模型、开关联网搜索、备份数据。
