========================================
   升级到 v2.5.0 Flash —— 请先看这一页
========================================

  这一版是「界面 + 搜索」更新：引擎没换，装法跟以前一样，
  装到同一个文件夹即可，不需要特殊操作。


【最重要的先说：我的东西会不会丢？】

  不会。对话记录 / 个人资料库 / 长期记忆 / API Key 与模型配置 /
  自己导入的技能，全部原样保留，升级只替换程序文件。
  升级前程序仍会自动把 data 目录备份到 data\_auto_backup\。


【怎么升级（三步）】

  第 1 步  双击新的安装包「Academy辩论教练-安装版.exe」
  第 2 步  「安装位置」选择和上次【同一个】文件夹
            （显示「未检测到已有安装」就是选错了，会装成两份）
  第 3 步  点「开始安装」，装完自动打开


【这一版改了什么（v2.4.2 → v2.5.0）】

  · 界面：全站主色换成 #120A8F（深靛蓝），两套并存的调色板合并成一套；
    字号/字间距按 macOS HIG 文本阶梯校准（11/12/13/15/17/22/26）。
  · 侧边栏：展开/收起改为顶栏左上角一个按钮（对齐 DeepSeek Harness），
    图标翻转表示状态，宽度 320ms 指数缓出。
  · 动效：按钮按下回弹、菜单淡入、模态 280ms scale+fade；
    系统开启「减少动态效果」时全部归零。
  · 关闭窗口：点 × 先问「最小化到托盘 / 直接关闭 / 取消」，
    可勾选「记住我的选择」；设置 → 通用 里可固定行为。
  · 搜索：DeepSeek 把联网搜索独立成 /v1/tools/search，本版改走新接口，
    同一个 DeepSeek Key 即可；自定义搜索新增「DeepSeek 官方搜索」预设。
  · 关于应用：新增「产品反馈」二维码。


【遇到问题】

  设置 → 关于应用 里能看到版本号，确认显示 v2.5.0 即升级成功。
  有问题进 QQ 群 386631298，或扫「关于应用 → 产品反馈」的二维码。
