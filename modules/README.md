## 注意力机制 v5.0

```
备赛请求
  ├─ 一级: prep.md 指向的核心文件（必加载）
  │   └─ 逻敏 + 丁冠羽 + 交互引导协议 + A→B→C + 标准备赛九步法 + 不协调而获视角
  ├─ 二级: 场景加载（赛制/对手/经典战例）
  ├─ 三级: 赛事蒸馏
  └─ 四级: 互联网搜索

复盘请求
  ├─ 一级: 逻敏 + 丁冠羽 + 主线形态诊断 + 结构性交锋 + 三维评判模型
  ├─ 二级: 方法论参考 + 历史复盘
  └─ 三级: 新国辩赛事蒸馏

评赛请求
  ├─ 一级: judge-assistant/SKILL.md + 三维评判模型 + 主线形态
  ├─ 二级: 判准卡 + 战术理解（逻敏/丁冠羽）
  └─ 三级: 赛制核对
```
