========================================
   升级到 v2.4.1 —— 请先看这一页
========================================

  这一版是「小更新」：引擎没换，只修问题、加功能。
  装法与以往一样，装到同一个文件夹即可，不需要特殊操作。

  （如果你是从 v2.3.x 或更早升上来：那一版换过底层引擎，
    请照旧用「完整安装包」升级，不要用「修复补丁」——
    原因见下面【为什么不能用「修复补丁」升级】。）


【最重要的先说：我的东西会不会丢？】

  不会。你的这些内容全部原样保留，升级只是替换程序文件：

    · 对话记录 / 收藏 / 辩题档案
    · 个人资料库（你上传的备赛包、文字稿、期刊）
    · 长期记忆与每日流水
    · API Key 与全部「模型配置」档案
    · 你自己导入的技能（插件）

  另外升级前程序会自动把数据打包备份一份（见下面第 4 步），
  万一有意外，随时能退回去。


【怎么升级（三步）】

  第 1 步  双击新的安装包「Academy辩论教练-安装版.exe」

  第 2 步  看第一屏的「安装位置」：
            · 请选择和上次【同一个】文件夹
              （默认是 C:\Users\你的用户名\AppData\Local\AcademyDebateCoach）
            · 这一屏会告诉你「检测到已有安装 vX.X.X：这是升级，
              你的对话记录 / 资料库 / API Key 都会保留」
            · ★ 如果显示「未检测到已有安装（全新安装）」，
              说明你选错文件夹了 —— 换成旧的那个，否则等于装了两份，
              记录还在旧目录里，新装这份是空的。

  第 3 步  点「开始安装」，等它走完，自动打开软件。
            第一次打开会比平时慢几秒：程序在给自己做体检。


【升级后第一次打开，程序会自动做四件事】

  1. 把 data 目录整份备份到 data\_auto_backup\（带日期，最多留 10 份）
  2. 重建引擎需要的配置文件
  3. 清掉旧引擎留下的运行日志（这些日志软件自己不看，旧格式留着没意义）
  4. 检查引擎能不能正常启动

  以上都是自动的，你不用管。做完正常聊天即可。


【这一版改了什么（v2.4.0 → v2.4.1）】

  · 新增：输入框旁把「模型」和「思考强度」合成一个控件，
    拖一条滑条就能调推理深度，越往右越"通电"（紫色星云 + 星尘）
  · 新增：左侧对话列表改成两行 —— 标题 + 「多久前活跃」+ 最后一条消息摘要，
    对话多了会显示「显示更多」
  · 修复：统计面板 / 用量一直显示 0（记账的字段名写错了）
  · 修复：若干界面问题（弹窗切页跳动、关闭按钮空白、设置面板横向滚动条、
    欢迎页能滚动、长标题压住时间）
  · 修复：安装包里缺了两个「文件关联」开关脚本


【出问题了怎么办】

  Q：升级后发消息报错，说引擎有问题？
  A：看软件里「设置 → 关于应用」的版本号是不是 v2.4.1，是的话把报错截图发群里
     （QQ 群 386631298）。你的数据都还在，不用慌。

  Q：想退回老版本？
  A：两步：
     ① 装回老版本的完整安装包（装到同一个文件夹）。安装从不删除 data，
        所以你的记录会跟着回去。
     ② 如果发现数据也被改坏了：打开安装目录下的 data\_auto_backup\，
        里面有一份升级前的备份，把它的内容拷回 data\ 对应位置即可。

  Q：为什么不能用「修复补丁」升级？
  A：补丁只替换程序文件、故意不碰运行环境（引擎），所以它没法换引擎。
     v2.4.0 换过引擎，必须用完整安装包 —— 这也正是补丁永远改不坏引擎的原因。
     从 v2.4.0 起引擎没再换过，普通小更新用完整安装包仍是推荐做法。


【常见问题】

  Q：安装包多大？装完占多少？
  A：安装包约 180MB，装完约 180~250MB（旧的引擎文件会被清掉，不会越装越大）。

  Q：装的时候提示要关掉软件？
  A：安装程序会自动帮你关掉正在运行的旧版本，不用手动关。

  Q：Windows 弹「已保护你的电脑」？
  A：点「更多信息」→「仍要运行」。程序没买微软签名，这是正常提示。

  Q：杀毒软件报警？
  A：选择「允许 / 信任」。本软件完全本地运行、开源免费。
