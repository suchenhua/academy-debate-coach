========================================
   Academy 辩论教练 - 安装说明（电脑小白版）
========================================

  看不懂这份？请看同目录下的「小白安装指南.md」，
  那份更详细、带截图级步骤说明。

【方法一：安装版（最简单，推荐）】
1. 双击「Academy辩论教练-安装版.exe」
2. 如果 Windows 弹出蓝色提示“Windows 已保护你的电脑”：
   点「更多信息」→ 点「仍要运行」
   （这是正常提示：程序没花钱买微软签名，不是病毒）
3. 等安装窗口自己走完（约 1~3 分钟），会自动弹出独立桌面窗口
4. 以后使用：直接双击桌面上的「Academy辩论教练」图标

【方法二：便携版（如果方法一被拦截）】
1. 右键压缩包 → 全部解压缩 → 解压到一个文件夹
2. 打开文件夹，双击「一键安装.bat」
3. 之后同方法一

【方法三：完全不安装（临时用）】
1. 解压后双击「start.bat」（或「启动辩论助手(Electron桌面版).vbs」）
2. 弹出的独立桌面窗口不要关，关了软件就退出

【第一次打开后要做什么】
点右上角「设置」→ 选 API 服务商 → 填 API Key → 保存。
详见「使用说明.txt」。

【常见问题】
Q：双击 exe 没反应？
A：等 1 分钟；如果还是没反应，先用方法二安装。

Q：杀毒软件报警？
A：本程序是本地运行的绿色软件，选择“允许/信任”即可。
   如不放心，用方法二或方法三，不运行 exe。

Q：怎么卸载？卸载后我的对话记录还在吗？
A：开始菜单 → Academy辩论教练 → 卸载 Academy辩论教练。
   也可以直接运行安装目录里的 uninstall.bat。
   ★ 卸载时会自动把你的数据（对话记录、API Key、个人资料库）
     打包备份到桌面的「Academy辩论教练-数据备份」文件夹，
     是一个带日期时间的 zip。所以不用担心数据丢失。
   ★ 千万不要手动删除安装文件夹，那样不会自动备份。

Q：重装后怎么恢复以前的记录？
A：把备份 zip 解压，里面的 data 文件夹放回安装目录即可。

Q：安装需要多大空间？
A：安装包约 204MB。
   安装过程中临时需要约 750MB（解压 + 复制）。
   装完后占用约 546MB，其中绝大部分是内置的运行环境
   （Node.js + Electron），因为这样你才不需要装任何东西。
   安装完成后临时文件会自动删除。

Q：能装到 D 盘吗？
A：当前版本固定装到 C 盘用户目录
   （C:\Users\你的用户名\AppData\Local\AcademyDebateCoach）。
   想放 D 盘请用「方法二/三」的便携版，解压到哪就在哪。

【系统要求】
Windows 10 / 11，64 位系统，能联网，有可用硬盘空间（建议 1GB 以上）。
