========================================
   升级到 v2.4.0 —— 请先看这一页
========================================

  ⚠️ 这一版和以往的小更新不一样：换掉了底层的 AI 引擎（DSH 内核）。
     所以请按下面的「完整安装包」方式升级，不要用以前的「修复补丁」。


【最重要的先说：我的东西会不会丢？】

  不会。你的这些内容全部原样保留，升级只是替换程序文件：

    · 对话记录 / 收藏 / 辩题档案
    · 个人资料库（你上传的备赛包、文字稿、期刊）
    · 长期记忆与每日流水
    · API Key 与全部「模型配置」档案
    · 你自己导入的技能（插件）

  另外升级前程序会自动把数据打包备份一份（见下面第 4 步），
  万一有意外，随时能退回去。


【怎么升级（三步）】

  第 1 步  双击新的安装包「Academy辩论教练-安装版.exe」

  第 2 步  看第一屏的「安装位置」：
            · 请选择和上次【同一个】文件夹
              （默认是 C:\Users\你的用户名\AppData\Local\AcademyDebateCoach）
            · 这一屏会告诉你「检测到已有安装 vX.X.X：这是升级，
              你的对话记录 / 资料库 / API Key 都会保留」
            · ★ 如果显示「未检测到已有安装（全新安装）」，
              说明你选错文件夹了 —— 换成旧的那个，否则等于装了两份，
              记录还在旧目录里，新装这份是空的。

  第 3 步  点「开始安装」，等它走完，自动打开软件。
            第一次打开会比平时慢几秒：程序在给自己做体检。


【升级后第一次打开，程序会自动做四件事】

  1. 把 data 目录整份备份到 data\_auto_backup\（带日期，最多留 10 份）
  2. 重建引擎需要的配置文件
  3. 清掉旧引擎留下的运行日志（这些日志软件自己不看，旧格式留着没意义）
  4. 检查新引擎能不能正常启动

  以上都是自动的，你不用管。做完正常聊天即可。


【出问题了怎么办】

  Q：升级后发消息报错，说引擎有问题？
  A：看软件里「设置 → 关于应用」的版本号是不是 v2.4.0，是的话把报错截图发群里
     （QQ 群 386631298）。你的数据都还在，不用慌。

  Q：想退回老版本？
  A：两步：
     ① 装回老版本的完整安装包（装到同一个文件夹）。安装从不删除 data，
        所以你的记录会跟着回去。
     ② 如果发现数据也被改坏了：打开安装目录下的 data\_auto_backup\，
        里面有一份升级前的备份，把它的内容拷回 data\ 对应位置即可。

  Q：为什么不能用「修复补丁」升级？
  A：补丁只替换程序文件、故意不碰运行环境（引擎），所以它没法换引擎。
     换引擎必须用完整安装包 —— 这也正是补丁永远改不坏引擎的原因。


【常见问题】

  Q：安装包多大？装完占多少？
  A：安装包约 180MB，装完约 180~250MB（旧的引擎文件会被清掉，不会越装越大）。

  Q：装的时候提示要关掉软件？
  A：安装程序会自动帮你关掉正在运行的旧版本，不用手动关。

  Q：Windows 弹「已保护你的电脑」？
  A：点「更多信息」→「仍要运行」。程序没买微软签名，这是正常提示。

  Q：杀毒软件报警？
  A：选择「允许 / 信任」。本软件完全本地运行、开源免费。
