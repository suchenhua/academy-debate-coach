```
| 赛事 | [名称] |
```

## 二、评判结果总览

```
独立评判结论：[胜方]获胜（X:X票型）

· 印象票 → [方]（理由：[一句话]）
· 环节票 → [方]（加权 X.XX vs X.XX，差距约X.XX分，[微弱/明显/一边倒]）
· 决胜票 → [方]（平台[i:j] / 论证[i:j] / 攻防[i:j]，[方]占优X:Y）

最佳辩手（3票）：
· [辩手名] × X票（[一句话理由]）
· [辩手名] × X票（[一句话理由]）

一句话概括：[全场胜负手——一句]
```

## 六、述票稿（可上台念）

**② 核心胜负理由**：

## 输出前检查

- [ ] 九段全部填写完毕了吗？
- [ ] 三票归属有明确理由吗？
- [ ] 最佳辩手3票分配清楚了吗？
- [ ] 辩手反馈每条都有替代方案吗？
- [ ] 能说出"如果X方做Y，我会改票"吗？
- [ ] 有没有替辩手补论证？（有→删掉）
- [ ] 字数约10,000字符吗？
