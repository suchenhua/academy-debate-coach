# 首质设计填写模板 v1.1

> 每条链3-4问。第一问必须"是/否"。
> 不是写问题列表——先想这条链在小结/自由辩里怎么收，再倒推怎么问。

---

## 链1：定义链

**目标**：确认对方定义 → 暴露对方定义的裂缝 → 收束到我方关键词

**填写**：

| 问题 | 对方答A→ | 对方答B→ |
|------|----------|----------|
| Q1（是/否）：[确认对方对XX的定义] | → Q2-A | → Q2-B |
| Q2：[按对方定义，XX算不算？逼判例] | → Q3 | → 转攻：那你方定义不等于没说吗？ |
| Q3：[收束]"所以你方也觉得______对吧？" | → 小结可收 | → 小结可收 |

**收束句**（留到小结说）：[回到己方关键词]"对方承认了______，这恰恰说明______"

---

## 链2：判准/平台链

**目标**：确认对方判准 → 逼对方用判准解释反例 → 暴露判准不自洽

**填写**：

| 问题 | 对方答A→ | 对方答B→ |
|------|----------|----------|
| Q1（是/否）：[确认对方判准] | → Q2 | → 那你们用什么比？ |
| Q2：[举反例——这个反例在你判准下该判给谁？] | → Q3 | → （如果在对方那边）那你的判准是不是预设了你的立场？ |
| Q3：[收束]"所以你方判准解释不了______" | → 小结可收 | |

---

## 链3：论点一链

**目标**：确认对方主张 → 拆机制 → 逼具体例子 → 拆例子

**填写**：

| 问题 | 对方答A→ | 对方答B→ |
|------|----------|----------|
| Q1（是/否）：[确认对方论点一的主张] | → Q2 | → 那你们到底在说A→B还是A→C？ |
| Q2：[拆机制]"A到B中间，我插一个Z，你怎么解释？" | → Q3 | → （如果对方解释不了）"所以A到B的因果链不成立" |
| Q3：[逼具体]"给我一个具体例子" | → Q4 | → 一个例子都没有吗？ |
| Q4：[拆例子]"在这个例子里，明明是Z在起作用，不是A→B" | → 收束 | |

---

## 链4：论点二链

同上结构。

---

## 链5：收编-反杀链（如有）

**适用场景**：对方有一个"标签"可以用数据反杀（如"被操控""功利打法""跟风"）

**填写**：

| 问题 | 动作 |
|------|------|
| Q1（是/否）：[确认对方的攻击标签] | 让对方自己说出来 |
| Q2：[如果真是你说的这样，为什么数据/案例证明相反？] | 甩数据反证 |
| Q3：[收编]"所以你说的这个______，恰恰证明了我方因为______" | 反杀 |

---

## 全部链写完后检查

- [ ] 每条链的Q1能回答"是"或"否"吗？（不能→重写）
- [ ] 每条链3-4问？（<3不够深，>5自己会断）
- [ ] 每条链画了分叉表吗？
- [ ] 每条链的收束句出现了己方关键词吗？
- [ ] 有没有用收编-反杀？（有对方标签吗？）
- [ ] 链之间有衔接吗？（定义链暴露的缝→判准链继续挖）
