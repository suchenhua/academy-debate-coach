# 主席词·填写模板 v1.1

> 参考原件：本地赛事行政资料库主席词
> 适用赛制：华语辩论世界杯（14环节）。其他赛制需调整环节表。

---

## 模板正文

```
尊敬的各位评委、各位辩手、现场以及线上的观众朋友们：

大家[上午/下午/晚上]好。

这里是[赛事全称]的现场，我是本场比赛的主席[姓名]。

本场比赛的辩题是：[完整辩题]。

坐在我右手边的是正方——来自[学校/队伍全称]的代表队，他们的立场是[正方立场]。
坐在我左手边的是反方——来自[学校/队伍全称]的代表队，他们的立场是[反方立场]。

下面请双方辩手进行自我介绍，首先有请正方。
（正方自我介绍）
感谢正方，下面有请反方。
（反方自我介绍）

本场比赛的评审是：
[评委1姓名]先生/女士
[评委2姓名]先生/女士
[评委3姓名]先生/女士
（如有更多）

在比赛开始之前，请允许我宣读提示铃声规则：
当各环节剩余30秒时，将听到一声铃响；
当各环节时间用尽时，将听到两声铃响，此时请停止发言。

现在我宣布——[赛事简称]正式开始。

首先是陈词一环节。有请正方一辩进行立论陈词，时间3分30秒。
（正方一辩立论）
感谢正方一辩。

下面是质询一环节。有请反方二辩质询正方一辩，时间2分钟。质询方可打断，被质询方不可反问，5秒保护。
（反方二辩质询）
感谢双方。

下面是陈词一环节。有请反方一辩进行立论陈词，时间3分30秒。
（反方一辩立论）
感谢反方一辩。

下面是质询一环节。有请正方二辩质询反方一辩，时间2分钟。
（正方二辩质询）
感谢双方。

下面是质询小结环节。首先有请反方二辩进行质询小结，时间1分30秒。
（反方二辩小结）
感谢。有请正方二辩进行质询小结，时间1分30秒。
（正方二辩小结）

下面是陈词二环节。有请正方四辩与反方四辩进行对辩，双方各1分30秒，交替发言，不可打断。
首先有请正方四辩。
（对辩）

下面是盘问环节。有请正方三辩盘问反方除三辩外任意辩手，时间1分30秒。
（正方三辩盘问）
感谢。有请反方三辩盘问正方除三辩外任意辩手，时间1分30秒。
（反方三辩盘问）

下面是盘问小结环节。首先有请正方三辩进行盘问小结，时间1分30秒。
（正方三辩小结）
感谢。有请反方三辩进行盘问小结，时间1分30秒。
（反方三辩小结）

下面是自由辩论环节。双方各4分钟，交替发言。首先有请正方。
（自由辩论）

下面是总结陈词环节。首先有请反方四辩进行总结陈词，时间3分30秒。
（反方四辩结辩）
感谢。有请正方四辩进行总结陈词，时间3分30秒。
（正方四辩结辩）

感谢正方四辩。

至此，本场比赛的所有环节已进行完毕。请工作人员收取评委评分表，请各位稍作等待。

（等待计票）

下面我宣布本场比赛结果：

印象票：[正方X票]对[反方X票]
环节票：[正方X票]对[反方X票]
决胜票：[正方X票]对[反方X票]

本场比赛的胜方是——[正方/反方]代表队。恭喜！

本场比赛的最佳辩手是——[辩手名]，[学校/队伍名]。

感谢各位评委、各位辩手、各位观众。本场比赛到此结束。

我们下一场比赛再见。
```

## 赛制适配速查

| 赛制 | 调整要点 |
|------|---------|
| 新国辩（18分钟自由分配） | 环节顺序不同：正方立论→反四质询正方一→反方立论→正四质询反方一→正方二申论→反三质询正二→反方二申论→正三质询反二→正三小结→反三小结→自由辩→反四结辩→正四结辩 |
| 奥瑞冈 | 增加"检证环节"和"举证责任"说明 |
| 2v2简化赛制 | 去掉三四辩环节，主席词简化 |

## 检查清单

- [ ] 赛制环节表核对无误？（逐个环节对照规则文件）
- [ ] 双方立场/队伍名确认无误？
- [ ] 评委名单确认无误？
- [ ] 时间数值与赛制一致？（3'30"→2'→1'30"→4'等）
- [ ] 铃声规则说明包含？
- [ ] 结果公布格式为三票分列？
- [ ] 最佳辩手宣布格式正确？
