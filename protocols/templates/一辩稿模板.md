# 一辩稿填写模板 v2.0（论证导向）

> 使用方式：不是自由写作。按以下结构逐段填写，每段写完后对照检查项。
> **总纲**：一辩稿是「数据机理实证 + 逻辑诠释」的论证文件，不是文学创作。论证是骨肉，修辞是皮毛。
> 配套规范：`prep-coach/SKILL.md` 4.1 节 + `prep-coach/一辩稿蒸馏方法论.md`（v5.1）。冲突时以后者为准。
> 黄金范本：`prep-coach/一辩稿黄金范本-晚一点向世界投降.md`，动笔前先读。
> 赛制决定字数。华语世界杯：850-1000字。新国辩：850-1000字。~250字/分钟。

---

## 段1：开场（~10%篇幅）

**先选类型**：
□ 价值辩·场景先行  □ 事实辩·开宗明义  □ 政策辩·先交代现状再定义
（反方可选"扔反例型"：先给一个实证反例占领直觉，再给定义）

**填写**：
```
[一个具体的人 / 一个具体的数字 / 一个具体的事件]

[从这个人/数字/事件自然切到辩题]

[一句话点出这道题在问什么——不是"今天我们要讨论的是"，是"这就是这道辩题的底色"]
```

**检查**：
- [ ] 第一句有没有面孔/数字/事件？
- [ ] 是不是"当今是什么时代"式空泛开场？（是→删掉重写）

---

## 段2：定义+判准（~10%篇幅）

**正方填写**：
```
[关键词1] = [大白话翻译]。[学术定义——一句够]。
[关键词2] = [大白话翻译]。[学术定义——一句够]。

这道题真正争的是 [不是A和B的词典意思，是A和B背后的理念分歧/路径选择]。
我方的判准是：[一句话——用什么标准判断辩题成立]。
```

**反方填写**：
```
对方把 [关键词] 定义为 [对方定义]。
但请看：[一个反例——对方定义解释不了的边界情况]。
所以我方重新定义：[新定义]。
我方的判准是：[一句话]。
```

**检查**：
- [ ] 定义能不能直接回答"那XX算不算"？
- [ ] 判准是不是一句话？（超过一句=太啰嗦）

---

## 段3：时代语境（~20%篇幅）

**填写**：
```
[宏观数据——一个让人记住的数字] + [这意味着什么]

[学术引用——一个社会学/心理学/哲学框架——一条够]

[切到具体的人/现实处境，三句以内]
```

**检查**：
- [ ] 数据后有没有"这意味着"？
- [ ] 学术引用是不是只有一条？（多则臃肿）
- [ ] 段末有没有落到具体的人/处境？（不能停在概念层）

---

## 段4：论点一（~25%篇幅）—— 走完四件套

**填写**：
```
[机理·论点句]：一句话机制判断（A→B→C 的"为什么"），不是现象描述

[数据]：数字 + 报告名/机构 + 年份

[实证]：访谈原文 / 具名案例 / 研究结论 / 事件——让数据有脸

[诠释]：这说明什么 / 这意味着什么 / 所以呢——材料到命题的推演
```

**检查**：
- [ ] 论点句是机制判断吗？能回答连续两个"那又怎样"？
- [ ] 每个论点至少 1 个可溯源数据（报告名+年份）？
- [ ] 每个论点至少 1 个真实实证材料（非编造）？
- [ ] 材料后紧跟"这意味着……"的推演？

---

## 段5：论点二（~25%篇幅）

格式同上（四件套）。

**额外检查**：
- [ ] 论点二和论点一的关系是？（纵深+横韧 / 微观+宏观 / 个人+社会 / 是什么+为什么）
- [ ] 如果论点二被击穿，论点一能独立支撑吗？
- [ ] 同一案例/数据不在两个论点间重复堆叠（只详写一次）

---

## 段6：收束（~10%篇幅）

**平实收束**，不堆金句、不写表演指导：

```
[回到辩题]："所以这道题问的其实是______"

[点出核心态度]：一句，点到为止。（可选）回扣开场的具体的人/事件，形成闭环

[收尾]：综上 + 立场句
```

**检查**：
- [ ] 没有新开论证、没有给新证据？
- [ ] 有没有一句态度收束（不是干巴巴的"综上感谢"，也不是硬凹金句）？
- [ ] ❌ 没有"（这句务必放慢）"等表演标注
- [ ] ❌ 没有硬塞"化用经典/排比/三层跳"

---

## 全文质检

写完从头到尾读一遍，逐项过：

- [ ] 每条论点走完四件套（机理/数据/实证/诠释）了吗？
- [ ] 每条数据后有解释句吗？
- [ ] 有没有类比/比喻在承担论证？（有→删，换事实或直接判断）
- [ ] 有没有编造的数据/访谈/案例？（有→删，不确定就标注待核实）
- [ ] 对方最可能的攻击在稿子中被提前回应了吗？
- [ ] 全稿没有表演指导、没有堆砌金句吗？
