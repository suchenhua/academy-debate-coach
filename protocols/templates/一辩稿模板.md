# 一辩稿填写模板 v1.1

> 使用方式：不是自由写作。按以下结构逐段填写，每段写完后对照检查项。
> 赛制决定字数。华语世界杯：850-1000字。新国辩：850-1000字。

---

## 段1：开场（~10%篇幅）

**先选类型**：
□ 下定义型  □ 给场景型  □ 喊话型
（反方可以选"扔反例型"）

**填写**：
```
[一个具体的人/一个具体的数字/一个具体的画面]

[从这个人/数字/画面自然切到辩题]

[一句话点出这道题在问什么——不是"今天我们要讨论的是"，是"这就是这道辩题的底色"]
```

**检查**：
- [ ] 第一句有没有面孔/数字/画面？
- [ ] 第一分钟（~200字）内出现了具体的人吗？
- [ ] 是不是"当今是什么时代"？（是→删掉重写）

---

## 段2：定义+判准（~10%篇幅）

**正方填写**：
```
[关键词1] = [大白话翻译]。[学术定义——一句够]。
[关键词2] = [大白话翻译]。[学术定义——一句够]。

这道题真正争的是 [不是A和B的词典意思，是A和B背后的理念分歧/路径选择]。
我方的判准是：[一句话——用什么标准判断辩题成立]。

预判对方会在 [哪个词] 上偷换，我方提前回应：[一句]
```

**反方填写**：
```
对方把 [关键词] 定义为 [对方定义]。
但请看：[一个反例——对方定义解释不了的边界情况]。
所以我方重新定义：[新定义——三个负向词连用描述对方动作]。
我方的判准是：[一句话]。
```

**检查**：
- [ ] 定义能不能直接回答"那XX算不算"？
- [ ] 判准是不是一句话？（超过一句=太啰嗦）
- [ ] 反方：有没有用反例开场再给定义？

---

## 段3：时代语境（~20%篇幅）

**填写**：
```
[宏观数据——一个让人记住的数字]
[学术引用——一个社会学/心理学/哲学框架——一条够]
[切到"我"：一个个人感受/经历。三句以内。自曝脆弱。]
```

**检查**：
- [ ] 数据后有没有"这意味着"？
- [ ] 学术引用是不是只有一条？（多则臃肿）
- [ ] 段末有没有切到具体的人？（不能停在概念层）

---

## 段4：论点一（~25%篇幅）

**填写**：
```
[场景：一个具体的人+处境+困境。2-3句。有转折。]
[主张：一句话，≤15字]
[机制：如果A→怎么→B→怎么→C。中间每一步讲清楚]
[证据：数据/案例 + 来源标注]
[收束：回到主张。对接下一层。一句。]
```

**检查**：
- [ ] 场景是不是完整小故事？（不是"比如XX"一句话带过）
- [ ] 场景有转折吗？（没有转折→只是举例，不是论证）
- [ ] 数据后有"这意味着"吗？
- [ ] 收束句有没有回到己方关键词？

---

## 段5：论点二（~25%篇幅）

格式同上。

**额外检查**：
- [ ] 论点二和论点一的关系是？（纵深+横韧 / 微观+宏观 / 个人+社会 / 是什么+为什么）
- [ ] 如果论点二被击穿，论点一能独立支撑吗？

---

## 段6：收束（~10%篇幅）

**选模式**：
□ 模式一（价值辩）：种收呼应+化用经典+三层跳+表演指导
□ 模式二（自我叙事）：用画面结束
□ 模式三（政策辩）：可执行方案关键词

**模式一填写**：
```
[回扣开场意象——不是重复，是点破]：
"一开始我讲了[开场的人/场景]，现在你应该知道了——[一句话点破这个场景背后的意义]"

[回到辩题]："所以这道题问的其实是______"
[回到人]："它对每一个普通人的意义是______"
[回到时代]："在我们这个时代选择______意味着______"

[化用经典+金句]："[一句评委一定听过的文本，赋予新意]"
[表演指导]：（这句务必放慢）
```

**检查**：
- [ ] 结尾意象和开场是同一个人/同一个场景吗？
- [ ] 三层跳是不是递进的同心圆？
- [ ] 有没有化用一句经典文本？
- [ ] 稿末有表演指导吗？
- [ ] ❌ 不是"综上，感谢"

---

## 全文质检

写完从头到尾读一遍，逐项过：

- [ ] 删掉所有删了也不影响论证的句子。缩水超15%吗？→ 删到15%以内
- [ ] 从头到尾有没有一个评委能记住的瞬间？（一个人/一只猫/一间出租屋）
- [ ] 每条数据旁边有解释句吗？
- [ ] 中间有"我"吗？（正方必须有）
- [ ] 对方最可能的攻击在稿子中被提前回应了吗？
- [ ] 表演指导标了吗？
