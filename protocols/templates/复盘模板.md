# 复盘报告·填写模板 v1.1

> 完整规范见 `review-coach/SKILL.md`。本模板是填写式辅助。
> 主流程：逐帧纠偏（≥70%篇幅）→ 汇总分析（≤30%篇幅）

---

## 一、比赛信息

```
辩题：[完整辩题]
对阵：正方 [队名] vs 反方 [队名]
赛制：[新国辩/华语世界杯/奥瑞冈/其他]
复盘类型：[文字稿复盘 / 录音复盘]

```

---

## 二、逐帧纠偏（主流程·≥70%篇幅）

> 按比赛时间线走。每个环节内部，在关键攻防处暂停。
> 暂停密度：一个质询链有四问，可能每问都要停。

### 环节1：正方一辩立论

```
[用自己话概括立论框架：定义+判准+论点1+论点2+价值]

🐉 **暂停**。
**问题**：[这个回应/开场/定义哪里不对——一句说清]
**话术**："[精确替代表述——可以直接上场念]"
**为什么**：[一句解释战术逻辑]
**对标公开赛事标杆**：[是/否首问？种收呼应？个人温度？表演指导？缺失项标记为"结构空白"]
```

（逐暂停重复此格式）

### 环节2：反方四辩质询正方一辩

（同上格式——逐暂停·话术·为什么·对标基准）

### 环节3：反方一辩立论 → 环节4：正方四辩质询反方一辩
### 环节5：正方二辩申论 → 环节6：反方三辩质询正方二辩
### 环节7：反方二辩申论 → 环节8：正方三辩质询反方二辩
### 环节9：正方三辩小结 → 环节10：反方三辩小结
### 环节11：自由辩论
### 环节12：反方四辩结辩 → 环节13：正方四辩结辩

## 三、汇总分析（≤30%篇幅）

### ① 全局性问题（2-3条）

逐帧中多次出现的模式性问题：
```
问题1：[逐帧中至少3次出现的同类问题]
→ 在各环节的表现：[立论时/质询时/自由辩时分别如何]
→ 改进方向：[一句]

问题2：（同上）
```

### ② 正赛改进清单（≤5条）

每条必须能从逐帧中找到对应暂停：
```
立论层：
1. [问题] → [改进话术]（对应环节X·暂停Y）

攻防层：
2. [问题] → [改进话术]（对应环节X·暂停Y）

结辩层：
3. [问题] → [改进话术]（对应环节X·暂停Y）
```

### ③ 学习要点（2-3条）

从这场比赛提炼的方法论收获。**不贴标签、不堆名字。**
```
1. [这场比赛教会我：一句话方法论]
2. [这场比赛教会我：一句话方法论]
```

---

## 输出前检查

- [ ] 逐帧按比赛时间线走了吗？（不是按概念分类）
- [ ] 每个暂停给了精确替代表述吗？（不是策略方向）
- [ ] "为什么"只有一句吗？（不是文章）
- [ ] 暂停之间有逻辑关联标注吗？
- [ ] 每个暂停对标了公开赛事质量基准吗？
- [ ] 全局性问题是从逐帧中提炼的吗？（不是凭空想的）
- [ ] 改进清单每条能从逐帧找到对应暂停吗？
- [ ] 不贴标签、不堆名字、不炫耀框架？
