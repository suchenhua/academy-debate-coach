## 标准操作流

```
收到辩论请求
→ 1. 读 必读加载协议.md → 确定任务类型 → 确认必读列表
→ 2. 读 核心知识最小集.md（备赛/复盘类任务）
→ 3. 按必读列表依次加载对应文件
→ 4. 打开对应模板，逐段填写
→ 5. 完成 → 逐项过检查清单 → 交付
```

**任何一步跳过 = 交付质量降级。**
