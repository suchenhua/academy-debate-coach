# 杨晨雪 · 判准卡

> 来源: 2026新国辩高校组资格赛官方判准量表
> 定位: 评委

## 背景
杨晨雪女士曾任武汉大学辩论队执行教练，曾代表武汉大学获得2020国际华语辩论邀请赛四强、2019年"晨星杯"首届全国大学生辩论巡回赛冠军、2019年"普世崇法杯"法制辩论赛亚军暨全程最佳辩手、2018年临潮杯冠军等荣誉。

## 判准十维

| 维度 | 选项 | 含义 |
|------|------|------|
| 分票倾向 | 从不 | 印象票可能因极其不适的语言/例子分票，但不纳入胜负判断 |
| 专业代入 | 重度 | 常识问题不接受无解释的反常识主张；专业领域主观带入论证义务划分 |
| 说服力优先级 | 推论优先 | 推论背后蕴藏的常识论据更丰富，同等效力下推论说服力更高 |
| 论证门槛 | 中等 | 有明确主张+学理/数据/案例/逻辑其一+诠释意义才算完成 |
| 共识推翻 | ❌不能 | 推翻共识=队伍内部出现分裂，论证矛盾必扣分；除非能完整解释矛盾 |
| 后场新点 | 正常 | 后半场新论点/回应完全接受；后结辩只接受新反驳，不接受新立论 |
| 心证调整 | 无 | 部分辩题有优势持方但不影响判准 |
| 违规厌恶 | 中等 | 遵守规则是基本，场上打急眼的小失误可接受 |

## 赢的定义
> 观点展现程度与被认可程度更高。以此为判准期待听到更有魅力的表达和多元丰富的想法。

## 应对策略

### 上场要点
- 推论为王：把"为什么"讲透比堆数据更重要，她认为推论背后的常识论据更丰富
- 表达要有魅力：赢的标准是"被认可程度"，内容和表达都要有感染力
- 后场正常接受新论点新回应（特别是后半场，不是结辩），可以临场应变
- 共识一旦达成不要推翻：她说推翻共识意味着"你与队友出现了分裂"，伤害判断
- 论证要完整：光有主张不够，必须配学理/数据/案例/逻辑之一并诠释意义

### 避免
- 避免推翻已达成的共识 — 她认为这暴露了队伍论证的内部分裂
- 避免反常识主张不给解释 — 武大教练背景意味着她对论证完整性要求不低
- 避免极其不适的语言或例子 — 会丢印象票
