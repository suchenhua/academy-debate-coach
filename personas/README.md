## 使用方式

- 查辩手风格："丁冠羽怎么打结辩？" → 加载 `丁冠羽.md`
- 查评委判准："陈凌岳论证门槛多高？" → 加载 `陈凌岳.md`（或查上表速览）
- 模拟对手视角：加载对应辩手卡片 → 按 `judge-assistant` 叠加判准偏好
- 双评委博弈分析：查两位评委十维差异 → 预判分歧点 → 制定安全策略
- 备赛避坑：查"共识不可推翻"列→面对这些评委绝不能推翻共识
