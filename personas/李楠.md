# 李楠 · 判准卡

> 来源: 2026新国辩高校组资格赛官方判准量表
> 定位: 评委

## 背景
李楠先生曾任武汉大学辩论队队长，代表武大、澳门科大斩获2020新国辩冠军暨全程最佳、2019世界大学生辩论巡回赛冠军、2018临潮杯冠军、2017全国网安辩论赛冠军。风格中正平和。

## 判准十维

| 维度 | 选项 | 含义 |
|------|------|------|
| 分票倾向 | 有时 | 印象票/决胜票统一；环节票独立按单环节打分；双方证成度接近时分票 |
| 专业代入 | 轻度 | 尽量少带入个人认知；极度反常识内容降低对手反驳门槛 |
| 说服力优先级 | 推论优先 | 赛场数据难以完整核验，逻辑周延、可解释数据矛盾的推论可信度更高 |
| 论证门槛 | 中等 | 逻辑推导完整+事实佐证+完整回应全场质疑 |
| 共识推翻 | ✅可以 | 允许推翻但越晚扣分越多，不建议结辩推翻核心共识 |
| 后场新点 | 较低（结辩❌不接受） | 自由辩新论点采信度低；结辩全新论点不认可+降低对方反驳举证要求 |
| 心证调整 | 无 | 辩题平衡由组委会负责，不主动降低劣势方评判标准 |
| 违规厌恶 | 中等 | 厌恶恶意逃质询/人身攻击，出现后环节大幅扣分 |

## 赢的定义
> 比较优势：双方持方均存在局限，胜负不在于完美无缺，而在于两点比较：①实证、反应、备赛层面的操作优势；②终局价值取向的感染力，让评委愿意认同己方选择。

## 应对策略

### 上场要点
- 比较的两条腿都要站稳：操作层面的实证优势+价值层面的感染力，缺一不可
- 推论优先，但要配事实佐证：他欣赏"追溯数据背后底层成因的交锋"
- 论证必须闭环：逻辑推导+事实佐证+回应全场质疑和遗留疑问
- 共识越早推翻越好：结辩推翻核心共识是最后的选择
- "中正平和"的风格偏好意味着过于激进的表达可能扣分

### 避免
- 避免结辩推翻核心共识 — "不建议，越晚扣分越多"
- 避免恶意逃质询/人身攻击 — 环节大幅扣分
- 避免单纯堆数据无逻辑 — "逻辑周延的推论可信度更高"
