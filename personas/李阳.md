# 李阳 · 判准卡

> 来源: 2026新国辩高校组资格赛官方判准量表
> 定位: 评委

## 背景
李阳先生为北京邮电大学、国防科技大学校辩论队教练、苹果派战队队长，曾代表队伍获国际华语辩论邀请赛八强，连续两年获得世界华语辩论锦标赛北京赛区冠军暨全程最佳辩手，执教队伍获2022年华语辩论世界杯冠军、2022年国际华语辩论邀请赛资格赛冠军及亚军、2023年华语辩论世界杯冠军及亚军。

## 判准十维

| 维度 | 选项 | 含义 |
|------|------|------|
| 分票倾向 | 有时 | 印象票给"纯看内容证成度更高"方；环节票按单环节表现打分；决胜票结合讨论补充 |
| 专业代入 | 轻度 | 先摒弃个人认知，发言贴合认知则对方反驳成本更高；政治立场刁难直接否定观点 |
| 说服力优先级 | 推论优先 | 数据/案例服务推论；极端无数据无案例场景下推论更有效；数据需解释、案例需证明非孤例 |
| 论证门槛 | 较高 | 期待辩手深挖论点、挖掘现实洞见；仅重复浅层观点不占优；论证完成度更高者胜 |
| 共识推翻 | ✅可以 | 致命共识可在后半段推翻但扣环节分；推翻逻辑越顺滑扣分越少 |
| 后场新点 | 较低 | 区分"原有论点延伸"和"全新独立论证线"；全新论证接受度大幅降低 |
| 心证调整 | 无 | 不主观判定优势持方，不主动调整心证，仅客观记录梳理交锋 |
| 违规厌恶 | 中等 | 重度违规：不听劝阻反打断/侮辱性发言/触碰直播底线；极端反社会言论可三票判负 |

## 赢的定义
> 完备：赢代表队伍完整挖掘辩题背后的社会、人性议题，完备完成数据、理论、逻辑、场景、价值全套论证；拒绝简单切割战场、回避深层矛盾，愿意完整辨析议题的队伍更容易获胜。

## 应对策略

### 上场要点
- 门槛高，别指望"混过去"：每个论点必须深挖到"现实洞见"层面，浅层重复不占优
- 推论是整个论证的灵魂：数据/案例只是服务推论的素材，推论必须讲透"为什么"
- 完备不是"全"而是"深"：不是论点越多越好，而是每个维度（数据/理论/逻辑/场景/价值）都做到位
- 共识可以推翻但要顺畅：推翻逻辑越顺滑扣分越少，但不能频繁翻悔
- 全新论点禁止后场出现：区分新论点和延伸——前者接受度大幅降低

### 避免
- 避免浅层重复展开论点 — 在他的框架下"持续深挖"才是胜负手
- 避免无解释的数据堆砌 — 数据需要解释才能被认可
- 避免简单切割战场回避深层矛盾 — 这直接违背他"完备"的判准核心
- 避免极端反社会/侮辱性言论 — 可三票判负
